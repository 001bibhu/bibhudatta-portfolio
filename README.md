# Bibhudatta Sahu — Portfolio

Static responsive portfolio website.

## Preview locally
Open `index.html` in a browser.

## Publish on Vercel
1. Create a GitHub repository and upload `index.html` and `resume.pdf` at the root.
2. In Vercel, choose **Add New → Project**, import the repository, and deploy with **Framework Preset: Other** (no build command needed).
3. Vercel provides a public `*.vercel.app` address. Share it with recruiters or connect a custom domain.

Alternative: deploy the folder using Vercel CLI (`vercel --prod`) after logging in.
